## About

A comprehensive, interactive discipleship study exploring the present reality of God's Kingdom through a fulfilled eschatology and covenant theology lens. This study challenges the popular "postponed Kingdom" narrative and equips believers to understand their current inheritance in Christ.

### Features

- 🌙 **Light/Dark Mode** - Toggle between themes for comfortable reading
- 📱 **Mobile Responsive** - Fully optimized for phones, tablets, and desktops
- ✅ **Interactive Quizzes** - Test your understanding after each section
- 📊 **Progress Tracking** - Visual progress bar and section completion
- 🏆 **Final Assessment** - Comprehensive 10-question exam with scoring
- 📖 **Scripture-Focused** - Built entirely on biblical references
- 💾 **No Dependencies** - Pure HTML, CSS, and vanilla JavaScript

### Key Themes

1. **The Kingdom is NOW** - Jesus declared the Kingdom "at hand," not thousands of years away
2. **Daniel's Prophecy Fulfilled** - Christ received His eternal Kingdom at the ascension
3. **The True Israel of God** - All who are in Christ are Abraham's heirs
4. **From Shadows to Substance** - The old covenant types find their fulfillment in Christ
5. **Living in the Unshakeable Kingdom** - Practical application for Kingdom living today

## Getting Started

### Option 1: Direct Use
Simply download `kingdom-discipleship.html` and open it in any web browser.

### Option 2: Host Online
Upload the HTML file to any web hosting service (GitHub Pages, Netlify, Vercel, etc.)

### GitHub Pages Deployment
1. Fork this repository
2. Go to Settings → Pages
3. Select "Deploy from a branch"
4. Choose `main` branch and `/ (root)` folder
5. Your study will be live at `https://yourusername.github.io/kingdom-of-god-discipleship/`
